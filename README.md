# mins

Набор маленьких минималистичных приложений для Wayland (Hyprland): календарь,
плеер, часы, секундомер, системный трей и уведомления. Все в одном стиле, все
берут цвета из одного файла палитры и перекрашиваются на лету, когда он меняется.

| Приложение | Что это |
|---|---|
| `minscal` | календарь с событиями: время, цвет, заметка, отметка «выполнено» |
| `minsplay` | мини-плеер для Spotify и любого MPRIS-плеера: визуализатор cava, громкость колесом мыши |
| `minsclock` | часы с датой |
| `minswatch` | секундомер |
| `minstray` | системный трей: иконки фоновых приложений и их меню |
| `minsnotify` | уведомления: всплывающие окна и история (заменяет swaync, mako, dunst) |

## Установка

### 1. Поставьте зависимости

**Arch Linux / CachyOS / EndeavourOS:**

```sh
sudo pacman -S git python-gobject gtk4 gtk4-layer-shell playerctl cava wireplumber \
               libnotify ttf-jetbrains-mono ttf-firacode-nerd
```

**Другие дистрибутивы:** нужны те же пакеты под своими именами: Python 3 с PyGObject,
GTK 4, gtk4-layer-shell, playerctl, cava, wireplumber (команда `wpctl`), libnotify,
шрифты JetBrains Mono и FiraCode Nerd Font.

### 2. Скачайте репозиторий

```sh
git clone https://github.com/<автор>/mins.git ~/mins
cd ~/mins
```

Папку можно положить куда угодно, но потом её нельзя переносить без повторного
шага 3.

### 3. Запустите установщик

```sh
./install.sh
```

Установщик ничего не ставит в систему и не требует `sudo`. Он:

- создаёт команды `minscal`, `minsplay`, … в `~/.local/bin`;
- добавляет приложения в меню и лаунчер (rofi, wofi, fuzzel и т. п.);
- регистрирует `minsnotify` как сервер уведомлений;
- проверяет зависимости и пишет, чего не хватает.

Если в выводе есть «не хватает», доставьте это и запустите `./install.sh` ещё раз.

### 4. Запустите

```sh
minscal      # или minsplay, minsclock, minswatch, minstray
minsnotify   # окно истории уведомлений
```

Повторный запуск того же приложения закрывает его окно, поэтому его удобно
вешать на горячую клавишу.

## Настройка Hyprland (по желанию)

Нужен Hyprland 0.55 или новее с конфигом на Lua.

**Уведомления.** Чтобы `minsnotify` принимал уведомления, уберите из автозапуска
старый демон (swaync, mako, dunst) и добавьте в `~/.config/hypr/modules/autostart.lua`
внутрь `hl.on("hyprland.start", ...)`:

```lua
hl.exec_cmd("~/.local/bin/minsnotify --daemon")
```

**Все приложения на одном экране.** Скрипт `mins-magic-layout` раскладывает
приложения тайлами на специальном рабочем столе `magic` (по умолчанию открывается
на SUPER+S):

```
┌─────────┬────────────┬──────────┐
│         │ minsnotify │          │
│ minscal ├────────────┤          │
│         │  minsplay  │ obsidian │
├─────────┼─────┬──────┤          │
│minswatch│tray │clock │          │
└─────────┴─────┴──────┴──────────┘
```

Obsidian ставить не обязательно: без него получится две колонки. Чтобы включить раскладку:

1. скопируйте правила из `hypr/rules.lua` в конец `~/.config/hypr/modules/rules.lua`;
2. добавьте в автозапуск:
   ```lua
   hl.exec_cmd("~/.local/bin/mins-magic-layout --hide")
   ```
   `--hide` прячет magic после сборки.

## Цвета

Приложения читают палитру из `~/.config/hypr/theme/current.css`. Если файла нет,
используются встроенные цвета. Чтобы задать свои:

```sh
mkdir -p ~/.config/hypr/theme
cp palette.example.css ~/.config/hypr/theme/current.css
```

и меняйте цвета в этом файле: открытые окна перекрасятся сразу. Палитру можно
положить и в другое место, указав путь в переменной окружения `MINS_THEME`.

Если у вас несколько палитр и вы переключаете их скриптом, сделайте `current.css`
символьной ссылкой на нужную палитру: приложения отследят смену ссылки.

## Управление

| Приложение | Клавиши и мышь |
|---|---|
| `minscal` | стрелки или `hjkl` — дни, PgUp/PgDn — месяцы, `t` — сегодня, `n` — новое событие, `e` — изменить, Del — удалить, пробел — выполнено, `a` — свернуть панель событий, `m` / `y` — выбор месяца и года, `s` — острые или скруглённые углы |
| `minsplay` | пробел — пауза, ←/→ — треки, колесо или ↑/↓ — громкость (до 150 %), `m` — выключить звук |
| `minsclock` | `s` или клик — показать или скрыть секунды |
| `minswatch` | пробел или клик — старт/пауза, `r` или правый клик — сброс |
| `minstray` | клик — открыть приложение, правый клик — меню, средний — второе действие |
| `minsnotify` | `d` — не беспокоить, Shift+Del — очистить историю |

Во всех приложениях Esc закрывает окно.

## Удаление

```sh
cd ~/mins
./install.sh --uninstall
```

Затем удалите папку репозитория. Данные приложений удаляются отдельно, если
они больше не нужны:

```sh
rm -rf ~/.local/share/minscal ~/.local/share/minsnotify ~/.cache/minsnotify \
       ~/.config/minscal ~/.config/minsclock
```
